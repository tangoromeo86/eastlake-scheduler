League Admin

Your job is the start and end of the season. The middle mostly runs itself.

In order:
  • 1. Set up the season
  • 2. Add programs and directors
  • 3. Let registration happen
  • 4. Generate the schedule
  • 5. During the season
  • Rain outs and scores
  • 6. Settle pending confirmations
  • Backups and restore
  • Starting next season

1. Set up the season

Go to Season. Set:

  • Season start — any date in your first week; it snaps back to that week's Monday.
  • Number of weeks — typically 10–12.
  • Games per team — the league default. Individual teams can ask for a different number.
  • Blackout dates — holidays and anything league-wide, one date per line as YYYY-MM-DD.

The Resulting Calendar below updates as you save, so you can see exactly which weeks and Saturdays you've created before anyone relies on them.

Then add your divisions (e.g. U10 Boys, U12 Girls), including each one's game length in minutes — this drives the sunset check below. A division can't be deleted while teams are still in it.

Kickoff times default to fixed times, adjusted for daylight. Weekday games default to 6:30pm; Saturday slots are 10:00, 12:00 and 2:00 and never move. As fall days shorten, a weekday game's default kickoff is pulled earlier automatically — using the field's actual location and the division's game length — so it's never scheduled to run past civil twilight (roughly half an hour after sunset). This affects both the initial schedule and every time option offered later during a change request, so nobody, coach or scheduler, is ever offered a slot that ends after dark. Coaches still don't pick times when setting availability — they only say whether they can play.

2. Add programs and directors

Go to Programs. Add a program per city or club, then add one director per program with their name, email and phone.

That's the last thing you have to do for that program's setup — the director takes it from here.

3. Let registration happen

Directors add their own fields and teams, and coaches fill in their own availability. You don't need to chase this in the tool; check the Teams tab to see how it's filling in. The Coaches section (under Programs) lets you fix a coach's contact details directly if something's wrong, without opening the full team editor.

The Fields tab shows each field's availability at a glance ("Fully open" or a summary of what's restricted) and lets you view and edit it directly — you don't have to go through a director to fix a field's hours. A team's first available day, if it has one, is set on the team itself by its director or coach; the scheduler respects it automatically wherever it's set.

4. Generate the schedule

Click Run Scheduler in the header and type run to confirm. A backup is taken automatically first, so this is always reversible.

The scheduler will:

  • Put games on Saturdays wherever possible — a weekday (Monday through Friday) is only ever used when no Saturday slot could take that matchup
  • Give every team its requested number of games
  • Keep home and away within one of each other for every team
  • Respect every team's and field's availability, including single-date exceptions
  • Cap every team at 2 games in any single week, and never schedule two games on consecutive calendar days for the same team — except Friday into Saturday, which is allowed, since a Friday game doesn't close off that Saturday the way any other adjacent pair would
  • Balance travel miles as far as geography allows

Any matchup it couldn't place is reported at the top of the page. It will still schedule everything else — one awkward pairing never costs you the rest of the division.

Check the Stats view for games, home/away split and travel miles per team.

5. During the season

Coaches sort changes out between themselves. You only get pulled in when something stalls:

  • A coach doesn't respond by their deadline → their director is emailed
  • Still nothing two days later → you are emailed
  • The two coaches keep swapping proposals without agreeing → both directors are looped in

Change Requests shows every live negotiation: which round it's on, whose turn it is, the deadline (overdue ones in red) and what's on the table. Click History on any game for the full story — who asked for what, when, and every escalation that fired.

Every game also carries a lightweight status — Scheduled, Pending (one coach has confirmed), Confirmed (both have), or Negotiating (an active change request). This is a signal, not a lock — a Confirmed game can still have a change requested against it later, same as any other. The Availability tab gives you the league-wide picture on a calendar, filterable by division, and switchable between team and field availability — useful when a division looks stuck and you want to see whose availability is actually the bottleneck.

Directors can now force a game past the rules — coaches can't. Directors have their own manual game editor (mirroring yours), scoped to games touching at least one of their own program's teams. If a real-world reason means a team genuinely needs a back-to-back or a 3rd game in a week, the director (or you) can save it anyway — the violation is shown plainly first, so it's never silent. Coaches stay entirely on the negotiated Request Change / Rain Out path, which never offers this override.

Rain outs and scores

Rain outs are coach-driven — either coach reports one from their own game (or their director does it for them), and it goes through the same propose/approve negotiation as a normal change request, just starting from "pick a new day" since the whole original day is gone. Once both sides agree, the original game is marked cancelled (kept as history) and a new makeup game appears on the schedule. You still have a direct Rain Out button on a game's edit panel for a fast, one-step override — useful if a coach calls you directly instead of using the tool.

Scores work the same way, minus the negotiation: either coach, either director, or you can click Report Score on a played game and enter the result, with an optional note. The other side can correct it later if needed (a note is required on a correction, for the audit trail). Nothing needs confirming — a score just sits there, and after about a week without further correction it reads as final. Every division's results roll up into a Standings tab on the public schedule page.

6. Settle pending confirmations

Games are never hard-locked — a change can be requested on any game at any point in the season, right up until it's played. What used to be Finalize Games is now Settle Pending Confirmations: a one-time sweep that force-confirms anything still sitting at Scheduled or Pending (treating a non-responding coach's silence as acceptance), while leaving anything actively Negotiating alone so you don't step on a live conversation. Run it whenever you want a clean read on what's actually settled — there's no wrong time, and nothing it does is irreversible.

Backups and restore

Backups lists your restore points. One is taken automatically before anything destructive (running the scheduler, uploading a season, importing a CSV, finalising, starting a new season), and you can take your own labelled one at any time.

Each restore point contains the season, roster, schedule and change requests together, so restoring always gives you a consistent league — never a schedule referring to teams that no longer exist.

Restoring is itself undoable. The current state is snapshotted before any restore, so if you roll back to the wrong point you can roll straight forward again.

Starting next season

Season → Start a New Season. It archives everything as a labelled restore point, keeps your programs, directors, fields and divisions (they carry over year to year), and clears teams, the schedule and any open change requests ready for fresh registration.
